# ApplyTrack – Job Application Tracker Dashboard

ApplyTrack is a responsive job application tracking dashboard that helps users organize and manage their job applications in one place.

## Features

- Add new job applications
- Edit existing applications
- Delete applications
- Track application status
- Search applications by company or role
- Filter applications by status
- Dashboard statistics
- Application analytics using Chart.js
- LocalStorage data persistence
- Responsive mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Chart.js
- LocalStorage

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start managing your job applications.

## Purpose

This project was developed to practice frontend development, JavaScript DOM manipulation, event handling, data management, and responsive web design.
